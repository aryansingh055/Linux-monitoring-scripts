# Linux Monitoring Scripts

A collection of simple Bash scripts for monitoring Linux system resources.

These projects are designed for beginners who want to practice shell scripting, Linux administration, and basic system monitoring.

---

## 📂 Projects

### 1. Monitoring Free RAM Space
Checks the available RAM and displays a warning if free memory falls below a specified threshold.

**Directory**
```text
ram-monitor/
```

---

### 2. Monitoring Free Disk Space Monitor with Email Alert
Monitors disk usage and sends an email notification using Postfix when disk usage exceeds the configured threshold.

**Directory**
```text
disk-monitor/
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/linux-monitoring-scripts.git
```

Go to the project directory:

```bash
cd linux-monitoring-scripts
```

Give execution permission to the scripts:

```bash
chmod +x *.sh
```

Run a script:

```bash
./script-name.sh
```
